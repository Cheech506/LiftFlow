# LiftFlow v0.3 Phone Release Checklist

Run this short pass in Expo Go before relying on LiftFlow at the gym.

## Install and persistence

- Open the app on an iPhone or Android phone and confirm the LiftFlow icon and dark theme.
- Confirm only Home, Exercises, Workouts, History, and Progress appear as tabs.
- Change the weekly goal in Settings, restart the app, and confirm Home and Progress keep the value.

## Active workout

- Start Upper A, enter values, change one set type, add RPE or RIR, and complete a set.
- Leave the workout screen and confirm the Resume bar stays above the five tabs without covering them.
- Pause and resume a rest timer; if enabled, confirm the lock-screen alert arrives.
- Finish the workout and start Upper A again; confirm the Previous column shows the completed values and tapping it copies them.

## Library and templates

- Create, edit, favorite, archive, restore, and safely delete a custom exercise.
- Create a template in a folder, edit its set values, duplicate it, move it, and start it.
- Confirm imported or custom muscle and equipment names appear in filter pickers.

## History and recovery

- Search by workout and exercise name, then switch among All, LiftFlow, and Strong.
- Navigate calendar months and open two workouts recorded on the same day if available.
- Edit a completed set, repeat the workout, and save it as a template.
- Delete a workout, restore it from Recently Deleted, then test permanent deletion with a disposable entry.

## Data transfer

- Export a full JSON backup and a history CSV.
- Import the provided Strong CSV and verify the preview before confirming.
- Confirm a second import reports only duplicates.
- Roll back the last Strong import, then restore the exported JSON backup.
