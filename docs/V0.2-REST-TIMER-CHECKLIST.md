# LiftFlow v0.2 Rest Timer Checklist

## Before testing

- [ ] Existing custom exercises remain present.
- [ ] Existing folders and templates remain present.
- [ ] Existing workout history opens normally.
- [ ] Any active workout resumes normally.

## Global settings

- [ ] Open Settings → Rest timer.
- [ ] Increase and decrease the global default by 15 seconds.
- [ ] Restart LiftFlow and confirm the value remains.
- [ ] Turn automatic start off and confirm completing a set does not start a timer.
- [ ] Turn automatic start back on.
- [ ] Enable lock-screen alerts and approve notification permission.
- [ ] Disable lock-screen alerts and confirm a currently scheduled alert is cancelled.
- [ ] Toggle haptic completion feedback.

## Exercise defaults

- [ ] Create a disposable exercise with a custom rest duration.
- [ ] Reopen the exercise and confirm its rest duration remains.
- [ ] Edit the rest duration and confirm the change remains after restart.
- [ ] Add the exercise to a template and confirm the saved rest value follows it.

## Template controls

- [ ] Open Edit Template.
- [ ] Increase and decrease an exercise's rest duration.
- [ ] Save the template.
- [ ] Reopen it and confirm the duration remains.
- [ ] Start the template and confirm the active workout uses the same duration.

## Active workout timer

- [ ] Complete a set and confirm the timer starts automatically.
- [ ] Confirm the top timer button displays the remaining time.
- [ ] Open the timer modal.
- [ ] Add 15 seconds.
- [ ] Subtract 15 seconds.
- [ ] Pause the timer.
- [ ] Navigate to another tab and return.
- [ ] Confirm the paused time remains.
- [ ] Resume the timer.
- [ ] Restart it and confirm it uses the full adjusted duration.
- [ ] Skip the timer and confirm the pending alert is cancelled.
- [ ] Open an exercise's `•••` menu and change its rest duration.
- [ ] Complete another set and confirm the new exercise duration is used.

## Recovery and alerts

- [ ] Start a timer and force-close Expo Go.
- [ ] Reopen LiftFlow and resume the workout.
- [ ] Confirm the timer reflects elapsed real time.
- [ ] Start another timer and lock the phone.
- [ ] Confirm the local notification appears when rest ends.
- [ ] Confirm sound behavior follows the device's notification/silent settings.
- [ ] Return to LiftFlow and confirm the Rest complete state appears.
- [ ] Finish a workout with a timer running and confirm no later alert appears.
- [ ] Discard a disposable workout with a timer running and confirm no later alert appears.

## Backup and migration

- [ ] Export a JSON backup.
- [ ] Confirm the backup reports storage version 7.
- [ ] Confirm rest-timer settings are included.
- [ ] Restore only after creating a separate safety backup.
- [ ] Confirm exercises, folders, templates, history, and timer settings remain correct.

## Project checks

- [ ] `npm run typecheck` passes.
- [ ] `npx expo-doctor` reports 18/18 checks passed.
- [ ] No visible controls overlap the iPhone status bar, keyboard, or safe area.
- [ ] Working tree contains only the intended Batch 0023 changes before commit.
