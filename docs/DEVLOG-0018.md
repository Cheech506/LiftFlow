# DEVLOG-0018 — Export

## Goal
Let the owner take workout data out of LiftFlow without a server.

## Completed
- Added CSV workout-history export with one row per set.
- Included workout date, names, notes, exercise notes, set number, type, weight, reps, RPE, RIR, and completion state.
- Added full JSON backup export for exercises, templates, active workout, and history.
- Added native share-sheet support and browser downloads.
