# LiftFlow v0.2 Tracking Types — Test Checklist

## Existing data safety
- Confirm all existing custom exercises remain present.
- Confirm all existing templates retain exercise order, set order, values, RPE/RIR, and set types.
- Confirm all existing completed workouts still open.
- Confirm archived exercises remain archived.
- Confirm the old Pull-Up/bodyweight workflow now displays as `Bodyweight & Reps`.

## Create one exercise of each type
Create a disposable exercise for each tracking type:
- Weight & Reps
- Bodyweight & Reps
- Bodyweight + Added Weight
- Assisted Bodyweight
- Reps Only
- Duration
- Distance & Duration

For each exercise, confirm only the relevant default fields appear and that the exercise remains after restarting Expo Go.

## Template builder
- Add all seven disposable exercises to one template.
- Confirm each exercise displays its tracking type.
- Confirm each set shows the correct input columns.
- Enter and save values for every metric: weight, added weight, assistance, reps, seconds, and distance.
- Add and remove sets.
- Reorder exercises.
- Save, close, reopen, and confirm every value remains.

## Active workout
- Start the test template.
- Confirm the planned values appear in the correct fields.
- Edit each supported metric.
- Copy previous values for each type.
- Complete at least one set of each type.
- Add a set to each exercise and confirm it copies only relevant metrics.
- Close Expo Go during the workout, reopen it, and resume.
- Confirm all values, completed states, notes, RPE/RIR, set types, and ordering remain.

## History
- Finish the test workout.
- Open full workout details and confirm each set is formatted for its tracking type.
- Edit one value for every tracking type and save.
- Close and reopen the workout to confirm the edits persist.
- Repeat the workout and confirm the correct inputs are restored.
- Save the completed workout as a template and verify its metrics.

## Export and backup
- Export workout history as CSV.
- Confirm the CSV includes Exercise Type, Weight / Added / Assistance, Reps, Duration Seconds, and Distance.
- Confirm each recorded set occupies one row.
- Export a full JSON backup.
- Open the JSON and confirm the storage version is 5.
- Complete a controlled backup/restore round trip using disposable data.

## Final checks
- Run `npm run typecheck` with no errors.
- Run `npx expo-doctor` and require all checks to pass.
- Force-close and reopen Expo Go three times.
- Confirm no required input or button is hidden by the keyboard.
- Confirm no visible control fails silently.
