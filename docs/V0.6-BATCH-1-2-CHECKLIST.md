# LiftFlow v0.6 Batch 1 & 2 Phone Checklist

Export a current JSON backup before installing the replacement files. Do not clear Expo Go data.

## Data migration

- Open LiftFlow and confirm Settings shows v0.6.0.
- Confirm the existing exercise count, folder count, template count, and completed-workout count look correct.
- Open several Strong workouts, native workouts, templates, and exercise-history pages.
- Export a new v0.6 JSON backup before editing real data.

## Workouts, folders, and templates

- Search for a template by template name, folder name, and exercise name.
- Create a template with the folder left blank and confirm it appears in Unfiled Templates.
- Move that template into a folder and back to Unfiled.
- Create, rename, reorder, archive, and restore a test folder.
- Edit planned sets, set types, values, rest time, RPE/RIR, exercise order, and supersets.
- Duplicate, archive, restore, and delete a test template.
- Confirm deleting a template or folder does not change completed History.

## Active workout

- Start from a template, rename the active workout, record sets, and leave the screen.
- Confirm the Workout in Progress bar remains above the five tabs and resumes the same workout.
- Add several exercises before closing the exercise picker.
- Test previous-value copy, set types, RPE/RIR, supersets, rest timer, Save for Later, resume, Finish, and Discard protections.

## Exercises

- Create a custom exercise with persistent instructions/notes.
- Close and reopen the app; confirm the notes remain on the exercise page.
- Test search, muscle/equipment/type filters, favorites, recents, edit, archive, restore, and safe deletion.
- Open exercises using each tracking type and confirm history, records, and charts remain correct.

## History

- Combine text, LiftFlow/Strong, date-range, template, and exercise filters.
- Export the filtered result set and open the CSV.
- Edit a completed workout's name, notes, date, start time, duration, exercises, exercise order, sets, values, set type, and effort.
- Confirm Home, Progress, exercise charts, and PRs recalculate after the edit.
- Test Repeat, Save as Template, Add Past Workout, Recently Deleted, Restore, and permanent deletion confirmation.

## Home, Progress, Settings, and backups

- Confirm Home shows real recent templates, current-week activity, recent PRs, and recent completed workouts.
- Confirm Progress range controls, weekly activity, volume, muscle groups, exercise trends, and records use real data.
- Change weight, distance, and preferred-effort settings; close and reopen the app and confirm they persist.
- Export workout-history CSV and a full JSON backup.
- Restore the new JSON backup and confirm all counts and recent workouts are unchanged.

## Final automated checks

```bash
nvm use
npm ci
npm run check
npx expo-doctor
```
