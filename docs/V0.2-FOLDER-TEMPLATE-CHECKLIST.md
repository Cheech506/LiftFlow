# LiftFlow v0.2 Folder and Template Checklist

## Existing Data

- [ ] Existing custom exercises remain available.
- [ ] Existing templates remain in their original folders.
- [ ] Existing template set values, RPE/RIR, and warm-up labels remain intact.
- [ ] Existing history still opens.

## Folder Management

- [ ] Create a new empty folder.
- [ ] Force-close and reopen Expo Go; confirm the empty folder remains.
- [ ] Rename the folder.
- [ ] Move the folder up and down.
- [ ] Attempt to delete a non-empty folder; confirm LiftFlow blocks it.
- [ ] Delete an empty folder.

## Template Management

- [ ] Duplicate a template and confirm all exercises and set values are copied.
- [ ] Move the duplicate to another folder.
- [ ] Move templates up and down inside a folder.
- [ ] Archive a disposable template.
- [ ] Confirm the archived template disappears from normal folders and Recent.
- [ ] Show Archived Templates and restore it.
- [ ] Permanently delete only a disposable template.
- [ ] Confirm exercises and history remain untouched.

## Persistence and Backup

- [ ] Force-close and reopen Expo Go.
- [ ] Confirm folder order, template order, moved templates, and archived templates persist.
- [ ] Export a JSON backup and confirm it reports storage version 6.
- [ ] Confirm the backup contains both `folders` and `templates`.
