# LiftFlow v0.2 Progress Dashboard Checklist

## Existing data

- [ ] Existing exercises remain available.
- [ ] Existing folders and templates remain available.
- [ ] Existing completed workouts still open normally.
- [ ] The Progress tab opens without a loading or rendering error.

## Date ranges

- [ ] 4W filters totals and charts to approximately the last four weeks.
- [ ] 12W filters totals and charts to approximately the last twelve weeks.
- [ ] 6M shows the last twenty-six weeks.
- [ ] ALL includes older completed workouts.
- [ ] A range with no workouts shows useful empty states instead of broken charts.

## Overview and weekly charts

- [ ] Workout total matches History for the selected range.
- [ ] Working sets exclude warm-up sets.
- [ ] Training time looks reasonable.
- [ ] Weight-based volume excludes warm-up sets.
- [ ] Weekly activity bars match the weeks in which workouts were completed.
- [ ] Weekly volume bars respond to edited or deleted workouts.
- [ ] Horizontal charts scroll on the iPhone without blocking vertical page scrolling.

## Muscle groups

- [ ] Completed exercises appear under their configured primary muscle.
- [ ] Set counts exclude warm-up sets.
- [ ] Percentages total approximately 100%.
- [ ] Custom exercises use their saved primary muscle.

## Exercise progress

- [ ] The exercise picker opens and closes cleanly.
- [ ] Only exercises with completed working sets appear.
- [ ] Selecting another exercise updates the chart.
- [ ] Weight exercises can switch between e1RM, Weight, Reps, and Volume.
- [ ] Other tracking types show only relevant metrics.
- [ ] Latest and Best values match completed workout data.
- [ ] Change updates when the date range changes.
- [ ] A one-session exercise shows a trend without a fake percentage change.

## Personal records

- [ ] Recent records show the exercise, metric, value, workout, and date.
- [ ] Warm-up sets do not create PR entries.
- [ ] Editing a record-setting workout recalculates the list.
- [ ] Deleting a record-setting workout restores the previous record progression.

## Final checks

- [ ] Force-close and reopen Expo Go; Progress still renders correctly.
- [ ] `npm run typecheck` passes.
- [ ] `npx expo-doctor` reports 18/18 checks passed.
- [ ] No existing local data was reset or migrated.
