# LiftFlow v0.2 — Exercise History and PR Checklist

## Existing data

- [ ] Existing exercises, folders, templates, settings, and history are still present.
- [ ] A renamed custom exercise still shows its older completed workout history.
- [ ] Archived exercises still show their performance history.

## Exercise details

- [ ] Open an exercise with no history and confirm the empty performance message is clear.
- [ ] Open an exercise with history and confirm session and completed-set totals are correct.
- [ ] Confirm the record cards fit without overlapping on the iPhone.
- [ ] Confirm recent PRs show a workout name, date, metric, and value.
- [ ] Confirm recent history shows the best set from each workout.
- [ ] Confirm warm-up-only work does not create a PR.

## Tracking types

- [ ] Weight & Reps shows weight, reps, e1RM, and volume records.
- [ ] Bodyweight & Reps shows a rep record.
- [ ] Bodyweight + Added Weight shows added-weight, reps, e1RM, and volume records.
- [ ] Assisted Bodyweight treats lower assistance as better.
- [ ] Reps Only shows a rep record.
- [ ] Duration shows a duration record.
- [ ] Distance & Duration shows distance, pace, and duration records.

## Active workout

- [ ] Start an exercise with prior history.
- [ ] Complete a set below the historical best and confirm no PR badge appears.
- [ ] Complete a set above a historical best and confirm the appropriate PR badge appears.
- [ ] Confirm a warm-up set never receives a PR badge.
- [ ] Uncomplete a set and confirm its PR badge disappears.
- [ ] Finish the workout and confirm the exercise detail records update.

## History edits

- [ ] Edit a completed workout to create a better record and confirm the record updates.
- [ ] Edit the record back down and confirm the record recalculates.
- [ ] Delete a disposable record-setting workout and confirm the previous record returns.

## Final checks

- [ ] `npm run typecheck` passes.
- [ ] `npx expo-doctor` reports 18/18 checks.
- [ ] Force-close and reopen Expo Go; calculated records remain correct.
