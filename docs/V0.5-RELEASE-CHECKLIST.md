# LiftFlow v0.5.1 Phone Release Checklist

Run this pass once on the phone that already contains the v0.3 Strong import. Export a JSON backup before beginning.

## Automatic migration

- Install/open v0.5 without clearing Expo Go data.
- Confirm all imported Strong workouts, templates, exercises, favorites, preferences, and Recently Deleted items remain present.
- Restart LiftFlow twice and confirm the same counts remain.
- Open Settings and confirm LiftFlow reports v0.5.1 with no local storage error.

## Stabilization

- Start a workout, enter a set, immediately lock the phone, reopen LiftFlow, and confirm the set remains.
- Leave the workout screen and confirm the persistent Resume bar remains above exactly five tabs.
- Test a rest timer with the phone locked and notifications enabled.
- Finish, edit, delete, restore, repeat, and export one disposable workout.

## Supersets

- Edit a template and group two adjacent exercises as a superset.
- Start the template and confirm both exercises show the same Superset label.
- Add a third exercise to the group, remove one exercise, and confirm a one-member group is automatically cleared.
- Finish the workout and confirm its History details retain the group through backup export/restore.

## Incomplete workouts

- Start a workout, complete at least one set, and choose Save Workout for Later.
- Start a different workout, save it for later, and confirm both appear under Workouts → Incomplete Workouts.
- Resume the first workout and confirm its values remain and the paused time is not added to workout duration.
- Delete the disposable incomplete workout and confirm the warning appears first.

## Past workouts and template history

- Add a past workout with a date, start time, duration, two exercise types, RPE/RIR, and notes.
- Confirm it appears on the correct History timeline and calendar date and updates Progress.
- Open a template preview, choose Workout History, confirm only workouts started from that template appear, then clear the filter.

## Data transfer and Strong history

- Export a v0.5.1 JSON backup and workout-history CSV.
- Confirm the CSV contains the Superset ID column.
- Import the complete Strong CSV and confirm a second import creates zero duplicates.
- Open several Strong-created exercises and confirm ALL shows their complete chart, PR timeline, and workout history.
- Confirm a completed `0 rep` Strong row remains in History but does not become a PR or chart point.
- Run Settings → Recalculate Progress & PRs and confirm it reports rebuilt exercises and qualifying sets.
- Roll back the import, restore the JSON backup, and confirm templates, incomplete workouts, supersets, and history all return.
