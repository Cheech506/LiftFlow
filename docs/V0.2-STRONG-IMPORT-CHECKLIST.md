# LiftFlow v0.2 — Strong Import Checklist

## Before importing

- [ ] Confirm current exercises, templates, folders, History, and Progress are visible.
- [ ] Export a normal LiftFlow JSON backup manually.
- [ ] Keep the original Strong CSV unchanged.

## Preview

1. Open **Settings → Export and backup → Import Strong CSV**.
2. Select the original Strong export.
3. Confirm the preview reports approximately:
   - 378 workouts ready on the first import
   - 52 missing exercises to create when using the current starter exercise library
   - 1,374 rest-timer rows skipped as sets
   - Date range from September 2023 through August 2026
4. Cancel once and verify nothing changes.

## Import

1. Start the import again.
2. Save or share the automatic pre-import JSON backup.
3. Complete the import.
4. Confirm History contains Strong badges.
5. Confirm imported workouts retain their original dates and durations.
6. Open several workouts and verify:
   - Weight and reps
   - Warm-up sets
   - Drop sets
   - Failure sets
   - RPE
   - Workout notes
   - Exercise notes
7. Confirm Strong-created exercises appear under Exercises.
8. Confirm existing matched exercises were not duplicated unnecessarily.
9. Confirm Progress and exercise PR pages recalculate from imported history.

## Duplicate protection

1. Import the exact same CSV again.
2. Confirm LiftFlow reports that all workouts already exist.
3. Confirm no duplicate workouts or exercises are added.

## Rollback

1. Open **Settings → Roll back last Strong import**.
2. Cancel once and verify data remains.
3. Start rollback again and save/share the automatic safety backup.
4. Confirm imported workouts disappear.
5. Confirm pre-existing LiftFlow workouts remain.
6. Confirm imported exercises that are not used elsewhere are removed.
7. Confirm any imported exercise added to a template is retained.
8. Restore the pre-rollback backup or reimport the Strong CSV for continued use.

## Persistence and export

- [ ] Force-close Expo Go and reopen LiftFlow.
- [ ] Confirm imported History remains.
- [ ] Export a LiftFlow JSON backup and confirm storage version is `8`.
- [ ] Export LiftFlow CSV and confirm the **Import Source** column shows `Strong` for imported workouts.
