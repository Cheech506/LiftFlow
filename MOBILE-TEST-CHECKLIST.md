# LiftFlow SDK 54 Mobile Test Checklist

## Navigation

- [ ] Home opens correctly.
- [ ] Exercises opens correctly.
- [ ] Workouts opens correctly.
- [ ] History opens correctly.
- [ ] Progress opens correctly.
- [ ] Settings opens from the top-right gear.
- [ ] No sixth Active Workout tab appears.

## Active workout

- [ ] Upper A starts from Home.
- [ ] Upper A starts from Workouts.
- [ ] Weight fields accept numeric input.
- [ ] Rep fields accept numeric input.
- [ ] Previous values can be copied.
- [ ] Completing a set updates the completed-set count.
- [ ] The rest timer starts.
- [ ] The persistent Resume bar appears above the tabs.
- [ ] The workout can be discarded.
- [ ] The workout can be finished without updating the template.
- [ ] The workout can be finished and update the template.

## Persistence

- [ ] An active workout survives closing and reopening Expo Go.
- [ ] Edited weights and reps survive closing and reopening Expo Go.
- [ ] Updated template values survive closing and reopening Expo Go.
- [ ] Completed workouts remain in History.
- [ ] Home weekly totals update.
- [ ] Progress totals update.

## Mobile layout

- [ ] Content does not overlap the iPhone notch or Dynamic Island.
- [ ] Bottom tabs do not overlap the home indicator.
- [ ] Buttons are comfortable to tap.
- [ ] Long workouts scroll correctly.
- [ ] The numeric keyboard does not cover the active set row.
- [ ] Finish and discard confirmation dialogs work.
